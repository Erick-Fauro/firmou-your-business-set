# firmou

Plataforma de agendamento e serviços locais.

> agenda marcada, horário firmado.

## Sobre

O Firmou é uma plataforma para simplificar o agendamento entre
prestadores de serviços locais e seus clientes.

O MVP começa pelo mercado de barbearias, permitindo que estabelecimentos
cadastrem serviços, profissionais e disponibilidade e disponibilizem
um link próprio para agendamento.

## Stack

- React
- TypeScript
- Supabase
- Lovable

## Estrutura

- `src/` — aplicação
- `supabase/` — configuração e migrations
- `docs/` — documentação do produto

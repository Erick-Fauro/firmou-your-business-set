# Firmou — MVP

## Objetivo

Construir a primeira versão funcional do Firmou para permitir que uma barbearia disponibilize sua agenda online e receba agendamentos.

## Profissional

- Criar conta e fazer login
- Cadastrar estabelecimento
- Cadastrar serviços
- Definir preço e duração dos serviços
- Cadastrar profissionais
- Definir horários de funcionamento
- Visualizar agenda
- Visualizar agendamentos
- Cancelar agendamento

## Cliente

- Acessar página pública do estabelecimento
- Escolher serviço
- Escolher profissional
- Escolher data
- Escolher horário disponível
- Informar nome
- Informar WhatsApp
- Confirmar agendamento

## Fora do MVP

Não fazem parte da primeira versão:

- Marketplace
- Pagamentos
- Avaliações
- Chat
- Aplicativo Android/iOS
- IA
- Programa de fidelidade
- Aluguel de equipamentos
- Prestadores externos
- Planos pagos

Essas funcionalidades poderão ser avaliadas após a primeira versão estar funcionando.
